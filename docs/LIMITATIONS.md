# Ограничения прототипа

- Используется собственный mock BilimClass; официальная интеграция не выполнена. Данные учеников, оценок, событий и достижений синтетические.
- Тематический граф задан в учебных данных, персональные значения рассчитываются алгоритмом. Индекс риска0–100 не является вероятностью провала; точность на учениках школы не измерялась.
- AI требует доступной модели, ключа и сети. Объяснения могут содержать интерпретации и не доказывают причин ухудшения успеваемости. Ошибка модели обозначается явно.
- Недельная сводка использует семидневное окно относительно даты демонстрационного учебного дня. Общий dashboard может охватывать более длинную историю.
- Планировщик рассчитан на небольшой один день. Глобальный оптимум окон/перестановок и полный школьный масштаб не заявляются; правила длительности требуют согласования при внедрении.
- Web Push зависит от браузера, сети и разрешений. Реальное получение двумя профилями при неактивной странице требует проверки в обычном браузере.
- Каталог подготовки содержит три англоязычных видео Khan Academy. Проверены страницы и предметная релевантность; воспроизведение зависит от устройства и сети.
- Локальный SQLite-снимок рассчитан на один процесс и постоянный диск. В Vercel используется PostgreSQL (Neon): весь снимок записывается под блокировкой одной строки, включая время AI-запроса. Такой вариант сохраняет данные между экземплярами, но ограничивает параллельную запись и требует переработки для школьного масштаба.
- Открытые demo-входы предназначены для синтетического прототипа. Посетители используют общее состояние и могут видеть изменения друг друга. Лимиты входа и AI сохраняются в БД; для пилота нужны личные учётные записи.
- В облаке нет постоянно работающего процесса уведомлений: ограниченная отправка запускается после записи, остаток очереди продолжает обрабатываться при последующих записях. Внутренние сообщения сохраняются независимо от внешней доставки.
- Цель закрывается учеником самостоятельно; прохождение учебного материала автоматически не измеряется. Однократное начисление баллов проверено.
