# Демонстрация

Подготовка: открыть [публичное демо](https://aqbobek-pulse.vercel.app) или запустить приложение локально, использовать разные профили браузера для ученика, учителя и администрации. У всех demo-пароль Pulse2026!. Данные являются синтетическими.

## Проход на 90 секунд

1. Ученик `student9@pulse.demo`: главная → граф тем → объяснение индекса СОЧ → «Получить» план подготовки. Показать маркировку источника AI и три видеоматериала.
2. Учитель `teacher@pulse.demo`: ранние сигналы и отчёт класса. Риск вычислен алгоритмом, текст — через LLM API.
3. Родитель `parent@pulse.demo`: данные своего ребёнка и «Выжимка за неделю». Недостаток данных отображается явно.
4. Администрация `admin@pulse.demo`: «Расписание» → выбрать Алию Маратову → «Отметить болезнь». Показать изменившегося учителя и новую версию, затем уведомление ученика и заменяющего учителя.
5. Открыть `/kiosk`: актуальные замены с временем, анонсы и топ дня, обновляемые без ввода.

## Дополнительный проход

- Ученик: «Цели и портфолио» → закрыть цель → баллы меняют топ дня; повторное действие не начисляет их снова.
- Добавить достижение с https-ссылкой, затем подтвердить учителем. Подтверждение сохраняет автора и время.
- Сравнить ленту `student9` и `student10`: адресное объявление 10-м отсутствует у 9-х.
- Администрация: доступность учителя/кабинета → сохранить → сгенерировать; создать занятие одного из типов. Для ленты создавать непересекающиеся группы с одинаковым ID ленты.
- Добавить тематическую mock-оценку в разделе учебной аналитики администрации; граф, риск и агрегаты читают одни данные.

## Настоящий Web Push

На localhost разрешён service worker; удалённому хосту нужен HTTPS. В отдельных профилях ученика и заменяющего учителя откройте «Уведомления» → «Включить уведомления» и разрешите запрос браузера. Подписка привязана к пользователю, поэтому повторно использовать её под другой учётной записью нельзя.

После подписки сверните страницу, администрацией выполните замену, проверьте фактическое получение системного уведомления обоими адресатами. «Принято push-сервисом» означает принятие сервером доставки, а не доказанное прочтение на устройстве. Внутренняя очередь работает независимо от подписки.

Если нет подходящего заменяющего учителя, отсутствие всё равно сохранено, предыдущие назначения помечены требующими решения. Невалидная новая версия не публикуется. Для повторения исходного сценария используйте отдельный свежий тестовый каталог БД; не удаляйте рабочие данные без необходимости.
