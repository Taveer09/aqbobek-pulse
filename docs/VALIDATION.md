# Проверка прототипа

Проверки выполнены локально на синтетических данных. Они подтверждают работу демонстрационных сценариев, а не внедрение в школе или прогнозную точность на реальных учениках.

## Повторяемые команды

```sh
npm run check
npm run smoke
```

Для `smoke` предварительно запустите `npm start`. Проверенное окружение: Node26.8.1, npm11.19.0. Общий линтер проекта не настроен.

## Автоматические проверки — 49/49

- **35 алгоритмических:** тематические оценки и предпосылки, 12 синтетических историй риска, недостаток и частичность данных, разделение предметов, посещаемость, группы и синхронные ленты, длительность, замены, возврат поиска, невозможные ограничения, лимит времени и независимая проверка готового расписания.
- **14 интеграционных:** вход/выход и серверные права, свой/чужой ребёнок, предметные ограничения учителя, адресная лента, очередь портфолио, подтверждение, однократное начисление, валидация оценки, версии расписания, сохранение отсутствия при невозможной замене, публичный Kiosk, семидневная сводка и отделение доставки от версии школьных данных.

Тесты не требуют API-ключа и не вызывают внешнюю модель. Метки синтетических сценариев не считаются независимой разметкой школьных исходов; accuracy/F1 на реальных данных не заявляются.

## Сквозной браузерный сценарий

Проверены входы ролей, закрытие цели, добавление и подтверждение достижения, административная генерация и замена учителя, адресное сообщение, таргетинг для разных параллелей и публичная стенгазета. Проверены ширины1440,768 и390px, горизонтального переполнения не обнаружено.

Успешными внешними API-вызовами отдельно проверены тьютор, отчёт класса и родительская недельная выжимка. Будущая доступность модели, квоты и стоимость зависят от выбранного аккаунта/поставщика.

## Уведомления

Проверены service worker, серверная очередь и внутренние адресные сообщения. Автоматизированное headless-окружение отказало в регистрации настоящей push-подписки, поэтому получение системных уведомлений двумя обычными браузерными профилями остаётся отдельной проверкой. Принятие сообщения push-сервисом также не доказывает доставку устройству.

## Что ещё нужно для пилота

Официальные обезличенные данные, согласованные правила групп/замен, проверка реальных ролей и уведомлений, наблюдаемые результаты работ для оценки и калибровки прогноза. Все экранные данные репозитория являются демонстрационными.
