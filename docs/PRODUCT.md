# Публичное описание продукта

Aqbobek Pulse — школьный портал для ученика, родителя, учителя и администрации. Документ описывает опубликованный прототип; исходный кейс и внутренние рабочие материалы сюда не входят.

## Сквозной сценарий

Тематическая оценка → карта освоения → объяснимый риск → рекомендация ученику и отчёт учителю. Отсутствие учителя → поиск допустимой замены → новая версия расписания → адресное сообщение и обновление стенгазеты.

## Пользователи

| Роль | Доступные действия |
|---|---|
| Ученик | Оценки, граф тем, рекомендации, свои цели и достижения |
| Учитель | Ранние сигналы назначенных классов/предметов, отчёт, подтверждение достижений |
| Родитель | Просмотр связанного ребёнка и недельная выжимка |
| Администрация | Радар, адресные объявления, занятия, доступность ресурсов и замены |
| Публичный Kiosk | Только анонсы, псевдонимы топа и актуальные замены |

## Границы

В наборе24синтетических ученика,4класса,1296тематических оценок и15назначений на один день. Есть уроки, пары, академические часы, мероприятия и синхронные профильные группы. Это выбранный объём демонстрации, не данные лицея.

Портфолио подтверждается отдельным пользователем. Цель получает баллы однократно. Данные родителя/учителя фильтруются сервером. Планировщик публикует только результат, прошедший независимую проверку; при невозможной замене отсутствие сохраняется и проблема остаётся видимой.

Индекс риска — эвристика, не вероятность. Граф предпосылок задан в учебных данных. Локальные тесты и синтетические истории не доказывают точность прогноза на реальных учениках.
